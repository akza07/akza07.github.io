## Why so minimal?

I always keep my notes minimal because I'm lazy I guess. The book only has bare essentials as this
is not a textbook. So do not use this as a learning material but only as a revision material.


This is a digital notebook which don't repeat same examples and stories too much so as to avoid
the following.

- Spoon feeding brain and I stop thinking or give an effort to understanding it.
- Re-iterating same basic things when all I want is to have a quick glance as a reminder of a
concept.
